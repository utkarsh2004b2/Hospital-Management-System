# Hospital Management System

A Java-based Hospital Management System developed using Core Java.

## Tech Stack

- Java
- IntelliJ IDEA

## Features

- Patient management
- Doctor management
- Add and view patient records
- Add and view doctor records
- Console-based application

## Project Structure

- `Main.java` - Application entry point
- `HospitalManagementSystem.java` - Main hospital management operations
- `Patient.java` - Patient-related data and operations
- `Doctor.java` - Doctor-related data and operations

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Open the project.
4. Run `Main.java`.
