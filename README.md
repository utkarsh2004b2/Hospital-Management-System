# Hospital Management System

A console-based Hospital Management System developed using Java and JDBC with MySQL.

## Tech Stack

- Java
- JDBC
- MySQL
- SQL
- OOP

## Features

- Add and view patient records
- Add and view doctor records
- Check patient and doctor records
- Appointment booking
- Database-driven record management
- Menu-driven console interface

## Project Structure

- `Main.java` - Application entry point
- `HospitalManagementSystem.java` - Main application and menu operations
- `Patient.java` - Patient management operations
- `Doctor.java` - Doctor management operations

## Database

MySQL is used for storing and retrieving patient and doctor records through JDBC.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database connection.
4. Update database credentials if required.
5. Run `Main.java`.
